# KINGSHOT 同盟ダッシュボード

同盟紹介、イベント予定、攻略ノートを同盟員に共有するための非公式ダッシュボードです。HTML・CSS・JavaScriptで動作し、サーバーやデータベースは不要です。

## 主な機能

- **同盟について**：同盟名・王国・タグ・紹介・方針・沿革・同盟アイコンを表示。
- **イベント情報**：巨熊狩猟（罠1・罠2）、聖剣争奪、バイキングの略奪、同盟争覇戦のエントリー締切、三盟争覇、チェーザレ討伐、王城決戦の予定を表示。
- **攻略情報**：複数のノートに文章と画像をまとめ、一覧から選択して閲覧。
- **スマホ対応**：予定の縦並び、コンパクトな文字サイズ、ノートタイトルのリンク風一覧。

日時の入力・表示はすべて日本時間（JST / UTC+9）です。開催日時は手動で設定し、ゲームとは自動連携しません。

## 編集用と公開用の違い

| ファイル | 用途 |
| --- | --- |
| `kingshot-alliance.html` | 管理者が手元で使う編集用ファイル。同盟情報・予定・ノートを更新します。 |
| 「共有用HTMLを保存」で生成したHTML | 閲覧専用ファイル。これを `index.html` に改名して公開します。 |
| `README.md` | この説明書。公開用リポジトリに配置します。 |

公開用HTMLには編集・画像追加・削除・保存の機能は含まれません。タブ切り替えとノート選択は利用できます。画像はHTMLに埋め込まれるため、別の画像フォルダーは不要です。
